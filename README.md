## 1. Objective
Is project ka main objective ek Python-based system banana hai jo students ke data ko read aur process karke unki academic performance ka analysis kar sake.

## 2. Technologies Used
* Python
* Pandas (Data manipulation aur analysis ke liye)[cite: 1]
* NumPy (Numerical calculations ke liye)[cite: 1]

## 3. Dataset Description
Project mein `students.csv` file ka use kiya gaya hai jisme 15 students ka data hai[cite: 2, 3]. Is dataset mein Student ID, Name, Department, 3 subjects ke marks, aur Attendance shamil hai[cite: 1].

## 4. Implementation
* **Data Loading:** Pandas DataFrame ka use karke CSV file ko load kiya gaya hai[cite: 1, 3].
* **Processing:** `functions.py` mein custom functions banaye gaye hain jo Pandas aur NumPy ka use karke total aur average marks calculate karte hain[cite: 1, 2].
* **Grading:** Conditions aur loops ka use karke grades aur Pass/Fail status assign kiya gaya hai[cite: 1, 2].
* **Analysis:** NumPy aur Pandas operations ka use karke class average, highest/lowest performance, aur subject-wise analysis kiya gaya hai[cite: 1, 2].

## 5. Key Features
* Automated total and average calculation[cite: 1].
* Dynamic grading system and Pass/Fail identification[cite: 1].
* Identification of top-performing students and best-performing subjects[cite: 1].

## 6. Final Outcome
Project successfully terminal par run ho raha hai aur clearly structured statistical analysis display kar raha hai, jisse class ki performance easily samajh mein aa rahi hai[cite: 2, 3].
